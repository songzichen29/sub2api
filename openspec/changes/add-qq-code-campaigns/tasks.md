## 业务约定

每群同时对应一个活动；保存所选群会切换该群的当前活动。支持每活动一次或每个北京时间自然日一次。库存为累计已分配码数，过期、停用和私聊失败不退名额。暂停只阻止新领取，已领取用户仍可补发原码。兑换码有效期从领取时起算，仅领取时绑定的站点账号可兑换。

活动奖励支持抽奖次数、余额USD、订阅天数和并发数。余额码不作为人民币支付订单充值；领码不直接增加任何权益。发出首码后锁定奖励类型、额度及领取频率。已分配码的有效期不随活动后续配置变化。

统计的当日签到与抽奖使用北京时间半开时间区间，网站和QQ按站点用户去重。当前抽奖次数使用全站账号、人民币实付本金、赠送台账和实际抽奖台账；持有人数只计未删除的正常账号。历史日期不改变“当前剩余次数”含义。汇总不受明细搜索筛选影响，导出遵循筛选并限制10000条，防止CSV公式执行。

## 验证范围

隔离库 `qqc_test`，无生产用户增减权益，无真实QQ群或私聊验收消息。线上仅核验统计与配置读写，可创建关闭且未分配群的临时活动并清理，不默认启用活动。

最终回归通过 QQ 前端组件与多语言 101 项测试、前端完整构建、qqcommunity 全包及活动/兑换相关后端测试、Bot 指令路由测试。两组最新二进制的隔离 MySQL 测试通过，补发失败保留原成功发送时间，删除兑换码仍保留领取和奖励明细。桌面与手机预览检查通过。
