## Why

用户需要直接在 QQ 群内完成站点账号绑定、余额查询、签到领奖、渠道状态查询及 AI 聊天，减少在群聊与 Sub2API 面板之间切换。当前生产分支缺少机器人与 QQ 身份关联能力。

## What Changes

- 在 Sub2API 内增加 QQ 社群机器人模块，通过 NapCat / OneBot v11 反向 WebSocket 接入普通 QQ 账号。
- 增加登录用户生成绑定码、QQ 提交绑定码、网站确认及解除绑定的完整流程。
- 提供本人余额查询、每日签到入账、权限范围内渠道状态与有上下文的 AI 聊天指令。
- 增加管理员配置、连接状态、绑定列表和奖励/消息记录页面，以及用户个人资料中的绑定入口。
- 默认关闭机器人与奖励；聊天使用运营方配置的站点专用 API Key，经本站网关正常计费，成员的绑定账号不承担共享 Key 的费用。
- 在 MySQL 与 PostgreSQL 迁移中同时增加身份绑定、绑定请求、事件去重、每日奖励和聊天额度记录，保留现有余额与鉴权缓存协议。

## Capabilities

### New Capabilities

- `qq-community-bot`: QQ 连接、账号绑定、本人余额、签到入账、渠道状态、聊天限额、管理配置与审计记录。

### Modified Capabilities

无。

## Impact

- Go 后端新增 qqbot 业务模块、仓库适配器、HTTP/WebSocket 路由及依赖注入。
- Vue 前端新增管理页与个人资料绑定组件，复用既有布局、表单、认证和国际化机制。
- 新增双数据库迁移，不引入新的外部消息队列或模型推理服务；QQ 登录由独立 NapCat 承担。
- 参考 DeanZFC/sub2api-custom 的交互设计，独立实现适用于本分支的核心功能，不整体合并其 PostgreSQL 专用模块。
